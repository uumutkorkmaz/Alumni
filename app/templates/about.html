Proje · YBSB3001

Proje Hakkında

Alumni Tracking System, İstanbul Üniversitesi İktisat Fakültesi Yönetim Bilişim Sistemleri (YBS) mezunlarının kariyer bilgilerini takip etmek amacıyla Web Programming (YBSB3001) dersi kapsamında geliştirilen bir web uygulamasıdır.

Ders

YBSB3001 — Web Programming

Durum

Geliştirme aşamasında

Backend

FastAPI (Python), MVC

Veritabanı

PostgreSQL · SQLAlchemy · Alembic

Yol haritası

Dört aşama
  1. Aşama 01

    Temel API iskeleti

    FastAPI projesi kuruldu, Docker & Docker Compose ile çalışır hale getirildi.

  2. Aşama 02

    Mezunlar ve duyurular

    Kullanıcı ve duyuru modelleri, JSON API ve tarayıcıdan yönetim sayfaları eklendi.

  3. Aşama 03

    PostgreSQL entegrasyonu

    Migration'lar, factory & seed ve ORM modelleri ile uygulama veritabanına bağlandı.

  4. Aşama 04

    İş ilanları ve başvurular

    Mezunlar iş ilanlarına başvurabiliyor; ilanlar ve başvurular hem API hem arayüz üzerinden yönetiliyor. Middleware, hata günlüğü ve genel 404 sayfası eklendi.
